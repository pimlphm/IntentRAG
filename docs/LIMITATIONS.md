# Limitations

1. The fresh evaluation is source-derived and strongly Cessna-weighted (212/214).
2. Retrieval support, quote coverage, parser success and citation presence are not semantic correctness.
3. The semantic judge experiment is unavailable: zero valid judgments were returned.
4. Several named baselines are controlled project implementations or style-inspired policies, not official reproductions. `data/metadata/method_registry.csv` records this distinction.
5. Long-term and Profile views compress documentary identity and must resolve to local evidence before supporting a claim.
6. The signed-prefix analysis uses observed compatibility fields; it does not independently prove authority, applicability or revision validity.
7. Actual KV reuse was measured on six independent query pairs in one runtime configuration. It is not a universal cache-hit or throughput result.
8. Canonical ordering increased input reuse while reducing a reference-visibility proxy, demonstrating a trade-off rather than a monotonic improvement.
9. Original manuals and text-bearing query-level data are withheld, so a public clone can verify reported aggregates and regenerate figures but cannot independently rebuild the corpus.
10. The manuscript is a working source that passed structural and content audits but still requires final author and publication-policy review.
