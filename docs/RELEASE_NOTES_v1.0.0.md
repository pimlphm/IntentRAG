# v1.0.0 Public Research Preview

This release freezes the first GitHub publication of the IntentRAG manuscript assets and expanded evaluation.

Included:

- current manuscript working source and audit reports;
- expanded and legacy research scripts;
- aggregate retrieval, evidence-coverage, memory-replay and actual KV results;
- independent English figures and plotted source tables;
- data, experiment, model and reproducibility documentation;
- publication manifest, checksum file and automated release audit.

Excluded:

- source manuals and processed source text;
- raw questions tied to source passages;
- prompts, full model answers and judge payloads;
- model weights, embeddings and runtime environments;
- local logs, credentials and personal paths.

The repository and sanitized release assets are publicly accessible. They remain all rights reserved while code ownership, co-author approval, data rights and manuscript-publication policy are reviewed.
