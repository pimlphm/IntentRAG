# Experiment Scripts

`expanded/` contains the October 2026 expanded evaluation scripts. `legacy/` preserves earlier project pipelines, figure builders and diagnostic code. `temporal_memory/` contains the long-/short-term evidence-memory diagnostics.

Local absolute paths were replaced by explicit placeholders during publication staging. Several legacy scripts are preserved for provenance and require path/config refactoring before reuse. The public clone cannot rerun the restricted corpus because the manuals and source text are not distributed.
